# Thruput Semgrep Rules (Python)

Curated Semgrep ruleset for Python codebases enforcing strict correctness, domain modeling immutability, failure handling, and security quality gates.

## Installation & Usage

```bash
# Add to dev dependencies
pip install "thruput-semgrep-rules @ git+https://github.com/thruput-io/semgrep.git#subdirectory=python"

# Run linter
thruput-semgrep .
# or
semgrep-python .
```
